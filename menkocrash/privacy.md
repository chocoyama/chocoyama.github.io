# メンコクラッシュ プライバシーポリシー

制定日: 2026年10月20日

chocoyama（個人開発者。以下「運営者」）は、ゲームアプリ「メンコクラッシュ」（以下「本アプリ」）の利用者の情報を、以下のとおり扱います。

## 1. 取得する情報

| 種類 | 内容 | 取得する場面 |
| --- | --- | --- |
| プレイヤーID | Unity Gaming Services が発行する、利用者ごとの識別子 | 初めて起動したとき |
| ゲームのデータ | 所持する英傑・勾玉・小判などの所持数、進み具合、購入の記録（App Store の取引ID、購入した商品、日時） | 遊んでいる間、購入したとき |
| 生まれた年 | 最初の起動で選んでいただいた年（端末と Cloud Save に保存） | 最初の起動時 |
| 連携したアカウント | Apple または Unity アカウントと連携したときの、そのサービスが発行する識別子（Sign in with Apple では、氏名とメールアドレスは受け取りません） | 「引き継ぎ」で連携したとき |
| ランキングの表示名 | ランキングに表示する名前（Unity Gaming Services が自動で付ける名前） | ランキングに参加したとき |
| 利用状況 | 対戦・ガチャ・広告の視聴などの記録、起動の記録、アプリのバージョン、端末の機種、OS のバージョン、端末の識別子（IDFV）、おおよその地域 | 13歳以上の利用者が遊んでいる間 |
| 広告に関する情報 | 広告識別子（IDFA。iOS のトラッキングを許可した場合のみ）、IP アドレス、端末の情報、広告の表示・視聴の記録 | 動画広告を見るとき |

運営者は、氏名・住所・電話番号・クレジットカード番号を取得しません。支払いは Apple の App Store で行われ、運営者が支払い情報を受け取ることはありません。

## 2. 利用目的

1. ゲームのデータを保存し、端末を替えても続きから遊べるようにするため
2. 購入を確かめて品をお渡しし、二重の付与や不正を防ぐため
3. 年齢に合わせて、広告の扱いと1か月に購入できる金額の上限を決めるため
4. 遊ばれ方を集計し、ゲームの調整と不具合の修正に使うため
5. 動画広告を表示するため
6. お問い合わせに対応するため

## 3. 利用している外部サービス

| サービス | 提供元 | 用途 | プライバシーポリシー |
| --- | --- | --- | --- |
| Unity Gaming Services（Authentication・Cloud Save・Cloud Code・Remote Config・Leaderboards） | Unity Technologies | プレイヤーの識別、データの保存、サーバーの処理、ランキング | [リンク](https://unity.com/legal/game-player-and-app-user-privacy-policy) |
| Unity Player Accounts | Unity Technologies | 引き継ぎのためのアカウント連携 | [リンク](https://unity.com/legal/game-player-and-app-user-privacy-policy) |
| Sign in with Apple | Apple Inc. | 引き継ぎのためのアカウント連携 | [リンク](https://www.apple.com/legal/privacy/) |
| UGS Analytics | Unity Technologies | 遊ばれ方の集計（13歳以上のみ） | [リンク](https://unity.com/legal/game-player-and-app-user-privacy-policy) |
| LevelPlay | Unity Technologies（ironSource） | 動画広告の配信 | [リンク](https://www.is.com/privacy-policy/) |
| App Store（アプリ内課金） | Apple Inc. | 勾玉などの販売 | [リンク](https://www.apple.com/legal/privacy/) |

各サービスには、そのサービスに必要な範囲で情報が送られ、提供元のプライバシーポリシーに従って扱われます。情報は、日本の外（アメリカなど）にあるサーバーに保存されることがあります。

法令に基づく場合を除き、上記以外の第三者に、利用者を特定できる情報を本人の同意なく提供しません。

## 4. 子どもの情報と広告

- 生まれた年から13歳未満の可能性があるときは、遊ばれ方の集計（UGS Analytics）に情報を送らず、広告は子ども向けの扱い（COPPA）にして、トラッキングの許可を求めません。
- 13歳以上の利用者には、広告の前に iOS のトラッキングの許可を求めます。許可しなくても本アプリは遊べ、許可は iOS の「設定」→「プライバシーとセキュリティ」→「トラッキング」からいつでも変えられます。

## 5. 保存期間

- ゲームのデータと購入の記録は、本アプリの提供を終えるまで、またはデータの削除を求められるまで保存します。ただし、法令で保存が必要なものを除きます。
- 利用状況と広告の情報は、各外部サービスが定める期間だけ保存されます。

## 6. データの開示・訂正・削除の窓口 {#requests}

利用者は、自分の情報の開示・訂正・削除・利用の停止を求められます。下の「お問い合わせ」へ、「設定 → アカウント → 引き継ぎ」に表示されるアカウント、または本アプリでのおおよその遊び始めた時期など、データを特定できる手がかりを添えてご連絡ください。本人であることを確かめたうえで、遅滞なく対応します。

Unity アカウントそのものは、Unity Technologies が管理しています。

- Unity アカウントの削除: [https://player-account.unity.com/delete-account](https://player-account.unity.com/delete-account)
- Unity アカウントの個人情報に関する問い合わせ: [unity-player-login-privacy@unity3d.com](mailto:unity-player-login-privacy@unity3d.com)

## 7. 安全管理

運営者は、外部サービスのアクセス制御を使い、情報の漏えいや不正なアクセスを防ぐ措置をとります。
