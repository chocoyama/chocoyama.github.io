# 資金決済法に基づく表示

本アプリ「メンコクラッシュ」の有償勾玉についての表示です。

| 項目 | 内容 |
| --- | --- |
| 前払式支払手段の名称 | 勾玉（有償勾玉） |
| 発行者 | chocoyama（個人開発者） |
| 支払可能金額等 | 上限はありません。ただし、年齢に応じて1か月に購入できる金額の上限があります（[利用規約](/menkocrash/terms/) 第3条） |
| 有効期間 | ありません |
| 使用できる範囲 | 本アプリ内で提供する有料のコンテンツ（ガチャ、灯の回復など） |
| 未使用残高の確認方法 | 本アプリのショップ画面で、有償勾玉と無償勾玉の所持数を確認できます |
| 利用上の注意 | 勾玉は有償勾玉から先に使います。購入した勾玉は払い戻しをしません（法令で定める場合を除きます）。他の利用者へ譲渡できません |
| 苦情・相談の窓口 | [chocoyama.dev@gmail.com](mailto:chocoyama.dev@gmail.com) |
| 約款 | [利用規約](/menkocrash/terms/) |
