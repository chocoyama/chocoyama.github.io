# 特定商取引法に基づく表記

| 項目 | 内容 |
| --- | --- |
| 販売業者 | 請求があれば遅滞なく開示します |
| 運営責任者 | 請求があれば遅滞なく開示します |
| 所在地 | 請求があれば遅滞なく開示します |
| 電話番号 | 請求があれば遅滞なく開示します |
| メールアドレス | [chocoyama.dev@gmail.com](mailto:chocoyama.dev@gmail.com) |
| 販売価格 | 各商品の購入画面に表示する価格（税込） |
| 商品代金以外の必要料金 | アプリのダウンロード・利用に必要な通信料は、利用者の負担です |
| 支払方法 | App Store の決済（Apple が定める方法） |
| 支払時期 | App Store の購入手続きを終えた時点 |
| 商品の引渡時期 | 購入手続きの完了後、ただちに本アプリ内でお渡しします |
| 返品・キャンセル | 商品の性質上、購入後の返品・キャンセルはお受けしません。App Store での返金は、Apple の定める手続きによります |
| 動作環境 | iOS 15.0 以降の iPhone（インターネットへの接続が必要です） |
| 未成年の購入 | 未成年の方は、法定代理人の同意を得てから購入してください。年齢に応じて1か月に購入できる金額の上限があります（[利用規約](/menkocrash/terms/) 第3条） |

販売業者の氏名・所在地・電話番号は、上のメールアドレスへご請求いただければ、遅滞なくメールでお知らせします。
